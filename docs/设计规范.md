# 算小智金融助手 - 设计规范文档

## 1. 设计理念

### 1.1 核心价值观
- **简洁高效**：减少视觉噪音，突出核心内容
- **信任感**：金融应用需要传达安全、专业的感觉
- **愉悦感**：通过精心设计的动效和色彩，让记账不再枯燥

### 1.2 用户体验原则
- **一眼可见**：关键数据一目了然
- **一键操作**：高频功能触手可及
- **一致体验**：跨平台保持统一的交互模式

## 8. 动效规范

### 8.1 缓动函数
```css
--ease-out: cubic-bezier(0.215, 0.61, 0.355, 1);
--ease-in-out: cubic-bezier(0.645, 0.045, 0.355, 1);
```

### 8.2 动画时长
- **快速**：150ms
- **常规**：300ms
- **慢速**：500ms

### 8.3 常用动效
- **页面进入**：淡入 + 向上位移 10px
- **卡片悬浮**：向上位移 4px + 阴影增强
- **按钮点击**：缩放 0.98

## 10. 可访问性规范

### 10.1 对比度
- 正文：至少 4.5:1
- 大文字（18px+）：至少 3:1

### 10.2 触摸目标
- 最小尺寸：44px × 44px

### 10.3 键盘导航
- 所有交互元素可通过键盘访问
- 聚焦状态清晰可见

## 11. 品牌应用

### 11.1 Logo 使用
- 最小尺寸：24px
