# 双模式架构迁移指南

## 目标
将历史单模式结构迁移为 C 端 + B 端双模式，并引入统一契约和 RBAC。

## 迁移步骤
1. 安装依赖：pnpm install
2. 校验配置：复制 .env.example 为 .env 并填写参数
3. 检查类型：pnpm typecheck
4. 运行测试：pnpm test && pnpm test:integration && pnpm test:e2e && pnpm test:perf
5. 启动服务：pnpm start

## 目录迁移对照
- 前端领域目录：src/domains/*
- 共享模块：src/shared/*
- 管理端：src/admin/*
- 后端 v1 路由：server/src/routes/v1/mobile 与 server/src/routes/v1/admin

## 数据库迁移
1. 更新 Prisma 模型（Role、UserRole 关联）
2. 执行迁移命令：
```bash
pnpm prisma migrate dev --schema server/prisma/schema.prisma
```

## 回滚方案
1. 保留迁移前数据库备份
2. 回退到旧版本代码并恢复备份库
3. 逐步恢复单模式入口

## 注意事项
- family 角色默认只读
- viewer 仅可访问报表读取能力
- AI 接口建议配置真实 DEEPSEEK_API_KEY 后再进入生产
