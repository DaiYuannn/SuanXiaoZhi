## 部署指南

### 1. 环境要求
- Node.js: >= 20
- pnpm: >= 9
- 数据库: SQLite（可演进 PostgreSQL）

### 2. 配置说明
- 使用 .env 配置 PORT、DEEPSEEK_*、AUDIT_* 参数
- 使用 server/prisma/schema.prisma 维护 RBAC 数据模型

### 3. 部署步骤
1. 安装依赖：pnpm install
2. 类型检查：pnpm typecheck
3. 测试：pnpm test && pnpm test:integration && pnpm test:e2e && pnpm test:perf
4. 构建：pnpm build
5. 启动：pnpm start

### 4. 回滚方案
1. 停止新版本服务
2. 恢复数据库备份
3. 切回前一版本代码并重启

## 双模式架构迁移说明

本次重构将历史单模式结构迁移为 C 端 + B 端双模式架构，关键变更：

### 目录迁移对照
- 前端领域目录：`src/domains/*`
- 共享模块：`src/shared/*`
- 管理端：`src/admin/*`
- 后端 v1 路由：`server/src/routes/v1/mobile` 与 `server/src/routes/v1/admin`

### 数据库迁移
更新 Prisma 模型（Role、UserRole 关联）后执行：
```bash
pnpm prisma migrate dev --schema server/prisma/schema.prisma
```

### 角色说明
- `family` 角色默认只读（仅 `transaction:read` + `family:read`）
- `viewer` 仅可访问报表读取能力
- AI 接口建议配置真实 `DEEPSEEK_API_KEY` 后再进入生产
