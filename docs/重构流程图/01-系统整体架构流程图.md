# 系统整体架构流程图

## 1. 系统架构总览

```mermaid
flowchart TB
    subgraph Client["客户端层"]
        Mobile["手机端APP内置浏览器"]
        Desktop["桌面浏览器"]
    end

    subgraph Frontend["前端应用层 - React + TypeScript + Vite"]
        Router["路由层<br/>React Router"]
        Pages["页面层<br/>17个业务页面"]
        Components["组件层<br/>通用组件"]
        Hooks["Hooks层<br/>业务逻辑封装"]
        API["API层<br/>HTTP请求封装"]
    end

    subgraph Backend["后端服务层 - Express + TypeScript + Prisma"]
        Middleware["中间件层<br/>Helmet/CORS/限流/日志"]
        Routes["路由层<br/>20个业务路由"]
        Services["服务层<br/>业务逻辑"]
        DB["数据访问层<br/>Prisma ORM"]
    end

    subgraph External["外部服务"]
        DeepSeek["DeepSeek AI API"]
        Tesseract["Tesseract OCR"]
    end

    subgraph Database["数据存储层"]
        SQLite["SQLite 数据库"]
        LocalStorage["本地存储<br/>离线数据"]
    end

    Client --> Frontend
    Frontend --> Backend
    Backend --> External
    Backend --> Database
    Frontend --> LocalStorage
```
