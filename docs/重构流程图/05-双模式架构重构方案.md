## 4. 权限控制流程

```mermaid
flowchart TD
    Start([用户请求]) --> IdentifyUser{识别用户类型}
    
    IdentifyUser --> |手机端| MobileUser{识别角色}
    IdentifyUser --> |B端后台| AdminUser{识别权限}
    
    MobileUser --> |本人| OwnerAccess["本人权限<br/>完全访问"]
    MobileUser --> |家庭授权人| FamilyAccess["家庭权限<br/>只读访问"]
    
    AdminUser --> |超级管理员| SuperAccess["超级权限<br/>全部功能"]
    AdminUser --> |运营人员| OperatorAccess["运营权限<br/>业务功能"]
    AdminUser --> |查看人员| ViewerAccess["查看权限<br/>只读功能"]
    
    OwnerAccess --> CheckResource{检查资源权限}
    FamilyAccess --> CheckResource
    SuperAccess --> CheckResource
    OperatorAccess --> CheckResource
    ViewerAccess --> CheckResource
    
    CheckResource --> |有权限| AllowAccess[允许访问]
    CheckResource --> |无权限| DenyAccess[拒绝访问]
    
    AllowAccess --> LogAccess[记录访问日志]
    DenyAccess --> LogDeny[记录拒绝日志]
    
    LogAccess --> End([处理完成])
    LogDeny --> End
```
