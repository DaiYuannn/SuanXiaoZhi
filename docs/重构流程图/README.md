## 查看方式

### VS Code
安装 "Markdown Preview Mermaid Support" 扩展，打开MD文件后按 `Ctrl+Shift+V` 预览。

### GitHub/GitLab
直接在仓库中查看MD文件，平台会自动渲染Mermaid图表。

### 在线工具
复制Mermaid代码到 [Mermaid Live Editor](https://mermaid.live/) 查看和编辑。

## 图表说明

### 流程图符号说明
- **圆角矩形**：开始/结束节点
- **矩形**：处理步骤
- **菱形**：决策判断
- **平行四边形**：输入/输出
- **圆柱**：数据库/存储

### 状态图符号说明
- **实心圆**：初始状态
- **圆环内实心圆**：结束状态
- **圆角矩形**：状态
- **箭头**：状态转换

### ER图符号说明
- **矩形**：实体
- **菱形**：关系
- **椭圆**：属性
- **线条**：连接关系
