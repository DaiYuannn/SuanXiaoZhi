## 2. 系统总览

### 2.1 产品定位
算小智记账系统是“记账 + 分析 + AI 助手 + 家庭协作 + 金融产品引导”的一体化系统，核心目标是：
- 降低记账成本（文字、图片、OCR）
- 强化消费认知（图表、分析、提醒）
- 提供面向风险偏好的产品建议（并做合规拦截）

### 2.2 技术栈
- 前端：React + TypeScript + Vite + React Router + Chart.js
- 后端：Express + TypeScript + Prisma + SQLite + Zod
- 安全与治理：Helmet、CORS、限流、统一错误格式、审计日志
- AI/OCR：DeepSeek 对话接口 + Tesseract OCR + 本地回退

### 2.3 部署模型
- 开发：前端本地 dev server 通过代理访问后端
- 生产：后端进程托管 API，同时托管前端静态资源并提供 SPA 回退
- 进程管理：PM2

## 4. 前端架构与流程

### 4.1 启动流程
1. [src/main.tsx](src/main.tsx) 挂载根组件
2. [src/App.tsx](src/App.tsx) 注入路由与全局边界
3. [src/router/index.tsx](src/router/index.tsx) 进行页面级路由分发
4. [src/components/MainLayout.tsx](src/components/MainLayout.tsx) 统一桌面/移动导航容器

### 4.2 网络请求流程
1. 页面调用 api 层
2. [src/api/endpoints.ts](src/api/endpoints.ts) 统一管理接口路径
3. [src/api/http.ts](src/api/http.ts) 处理超时、重试、错误映射
4. [src/config.ts](src/config.ts) 提供 base URL、审计端点、批量参数

### 4.3 助手流程
1. 页面或侧边助手触发用户输入
2. [src/hooks/useAssistant.ts](src/hooks/useAssistant.ts) 编排请求
3. [src/components/AssistantPanel.tsx](src/components/AssistantPanel.tsx) 渲染消息与状态
4. 后端失败时进入本地规则回退（已在客服等页面实践）

### 4.4 审计流程
1. 关键行为写入本地队列
2. [src/analytics/audit.ts](src/analytics/audit.ts) 按批次上报
3. 后端 audit 接口接收并落库/落日志
4. [src/hooks/useAuditReminder.ts](src/hooks/useAuditReminder.ts) 与提醒策略联动

## 13. 主要风险清单

1. 工作流构建已暂停，线上前缺少自动化质量闸口
2. 前端部分页面仍有 mock 数据，易与真实后端脱节

6. 家庭、激励、产品三条业务线耦合增加
7. 审计日志上报与业务请求并行，失败处理策略需统一
8. 环境配置分散于前端/后端，重构时容易遗漏
9. SQLite 在高并发/多实例下扩展有限
10. 测试覆盖以冒烟为主，缺少稳定单元与契约测试

## 16. 双模式架构重构方案

### 16.1 架构目标
将当前单一前端应用重构为双模式架构：
- **主模式**：手机端APP内置浏览器型服务功能
  - 支持用户本人完全访问权限
  - 支持家庭授权人只读访问权限
- **副模式**：面向B端用户的服务器后台管理中心
  - 满足便捷查看与管理需求
  - 支持多级管理员权限

### 16.2 手机端APP模式设计

#### 16.2.1 技术架构
```
手机APP容器
    └── JSBridge（原生交互）
        └── WebView组件
            └── React SPA应用
                ├── 路由管理
                ├── 状态管理
                ├── UI组件层
                └── 业务模块层
```

#### 16.2.2 权限模型
| 角色 | 权限范围 | 访问级别 |
|------|----------|----------|
| 用户本人 | 全部功能 | 完全访问（读写） |
| 家庭授权人 | 共享账本、家庭统计 | 只读访问 |

#### 16.2.3 核心功能模块
- 认证模块：登录/注册/Token管理
- 记账模块：手工录入/OCR识别/语音输入
- 分析模块：消费分析/财务规划
- AI助手模块：智能客服/意图识别
- 家庭模块：家庭管理/共享账本
- 激励模块：任务系统/积分奖励

### 16.3 B端后台管理模式设计

#### 16.3.1 技术架构
```
管理门户
    └── 后台前端应用
        ├── 仪表盘
        ├── 导航菜单
        └── 管理模块
            ├── 用户管理
            ├── 交易管理
            ├── 产品管理
            ├── 风险管理
            ├── 系统管理
            └── 报表管理
```

#### 16.3.2 管理员权限
| 角色 | 权限范围 | 功能访问 |
|------|----------|----------|
| 超级管理员 | 全部功能 | 完全控制 |
| 运营人员 | 业务功能 | 用户/交易/产品管理 |
| 查看人员 | 只读功能 | 数据查看/报表导出 |

#### 16.3.3 核心管理功能
- 用户管理：用户列表/权限分配/状态管理
- 交易管理：交易查询/异常处理/数据导出
- 产品管理：产品上架/下架/推荐配置
- 风险管理：风险评估配置/预警规则
- 系统管理：配置管理/日志审计/监控告警
- 报表管理：统计报表/数据导出/可视化

### 16.4 API网关设计

#### 16.4.1 路由分离
```
/api/v1/*          → 手机端API（用户本人）
/api/v1/family/*   → 家庭共享API（家庭授权人）
/api/v1/admin/*    → B端管理API（管理员）
```

#### 16.4.2 权限中间件
- 认证过滤器：Token验证/会话管理
- 角色过滤器：角色识别/权限校验
- 资源过滤器：资源访问控制
- 审计过滤器：操作日志记录

### 16.5 数据同步策略

#### 16.5.1 手机端数据流
```
用户输入 → 本地缓存 → 同步服务 → API网关 → 主数据库
```

#### 16.5.2 管理端数据流
```
管理查询 → 管理缓存 → 数据服务 → 主数据库/只读副本
```

#### 16.5.3 数据一致性
- 主从复制：读写分离
- 缓存策略：热点数据缓存
- 消息队列：异步数据同步

- **模板记账**：常用交易一键复用
- **智能推荐**：根据时间地点推荐分类

- **对话界面**：气泡对话，快捷指令标签
- **功能入口**：悬浮球全局唤起，侧边栏滑出

- **成员头像**：显示家庭成员头像列表
- **共享交易**：标记共享交易，显示分摊比例
- **账单分摊**：支持AA、按比例、自定义分摊

#### 游戏化激励
